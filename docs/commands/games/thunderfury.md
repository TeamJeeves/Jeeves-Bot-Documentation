## Thunderfury Command

### Description
The `thunderfury` command sends an embedded message with details about the legendary item "Thunderfury, Blessed Blade of the Windseeker" from World of Warcraft.

### Usage
```
/thunderfury
```

### Permissions
- **User**: No special permissions required.
- **Bot**: `EmbedLinks`

### Examples
- Trigger the Thunderfury command:
  ```
  /thunderfury
  ```

### Notes
- Ensure that Jeeves has the necessary permission to send embedded messages.
- The bot will reply with an embedded message containing the item's details, including its stats, effects, and a link to its Wowhead page.
