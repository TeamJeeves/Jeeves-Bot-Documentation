## Servers Command

### Description
The `servers` command helps users find popular community servers related to World of Warcraft.

### Usage
```
/servers
```

### Permissions
- **User**: No special permissions required.
- **Bot**: No special permissions required.

### Examples
- Find a popular community server:
  ```
  /servers
  ```

### How It Works
1. **Server Selection**: The bot presents a list of categories for community servers, such as Class Discord Servers, Collect Rare Items and Achievements, Great Warcraft Communities, Groups for Dungeons and Raids, and Your Favorite Warcraft Tools.
2. **User Interaction**: Users select a category from the provided options.
3. **Server Details**: The bot fetches and displays an invite link to the selected server.

### Notes
- The bot will reply with an error message if it cannot find information for the selected server.
- Ensure that Jeeves has the necessary permissions to send messages and interact with users.
