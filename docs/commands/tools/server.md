## Server Command

### Description
The `server` command provides information about the current server, including details about channels, members, roles, and server creation date.

### Usage
```
/server
```

### Permissions
- **User**: No special permissions required.
- **Bot**: `EmbedLinks`

### Examples
- Get information about the current server:
  ```
  /server
  ```

### Notes
- Ensure that Jeeves has the necessary permission to send embedded messages.
- The command will display information such as the number of text and voice channels, the number of members, the server owner, the number of roles, the server creation date, and the verification level.
