## Wowhead Command

### Description
The `wowhead` command allows users to search Wowhead for information related to World of Warcraft.

### Usage
```
/wowhead <search>
```

### Options
- **search** (required): The search term for the information you want to find on Wowhead.

### Permissions
- **User**: No special permissions required.
- **Bot**: No special permissions required.

### Examples
- Search Wowhead for information on a specific item or topic:
  ```
  /wowhead search:Fireball
  ```

### Notes
- The command will display the first result from the Wowhead search, including the title and link.
- The bot will reply with an error message if it cannot find any results for the specified search term.
